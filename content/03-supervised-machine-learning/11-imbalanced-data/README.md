## About
Understand the challenges of imbalanced data and apply techniques to address class imbalance in datasets.


## Learning Objectives

*You will be able to:*

- Describe when imbalanced data is a problem.
- Identify methods for handling imbalanced data and appropriately evaluating performance.
- Apply the `imbalanced-learn` library to oversample minority classes.
- Apply the `imbalanced-learn` library to create synthetic minority class observations.

## Prerequisites

- Interpret and use Python dictionaries.
- Build `pandas` `DataFrames` from dictionaries.
- Perform simple data manipulation on `pandas` objects.
- Understand bias / variance and implement train-test split.
- Machine learning workflow with `scikit-learn`, including `GridSearch`
