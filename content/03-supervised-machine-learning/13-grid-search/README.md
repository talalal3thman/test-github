## About
An introduction to optimizing machine learning models with grid search and pipelines in `scikit-learn`.

## Learning Objectives

*You will be able to:*

- Apply `GridSearchCV` to systematically search for optimal hyperparameters 
- Evaluate and interpret grid search results to select the best model configuration
- Implement `scikit-learn` pipelines to create reproducible machine learning workflows

| [Practice](./02-notebooks) | - Evaluate and interpret grid search results to select the best model configuration  |


## Prerequisites

- Interpret and use Python dictionaries.
- Build `pandas` `DataFrames` from dictionaries.
- Perform simple data manipulation on `pandas` objects.
- Understand bias / variance and implement train-test split.
- Machine learning workflow with `scikit-learn`.
