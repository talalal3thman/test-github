## About
Learn what support vector machines are and how they are used for linear or nonlinear classification; and build an SVM model in `scikit-learn`.


## Learning Objectives

*You will be able to:*

- Describe linear separability.
- Differentiate between maximal margin classifiers, support vector classifiers, and support vector machines.
- Implement SVMs in `scikit-learn`.
- Describe the effects of C and kernels on SVMs.

## Prerequisites
- Write and run Python code in a Jupyter notebook.
- Create basic Python functions.
- Have familiarity with `pandas`.
- Have familiarity with `scikit-learn`.
- Describe the difference between regression and classification.
- Evaluate the performance of regression and classification models.
- Understand the bias-variance tradeoff.
