## About
Learn the intuition and mechanics of decision trees and build, tune, evaluate, and visualize effective models.  (CART  = Classification and Regression Trees)

## Learning Objectives

*You will be able to:*

- Understand the intuition behind decision trees.
- Understand the CART algorithm that powers decision trees.
- Describe how decision trees use Gini to make decisions.
- Fit, generate predictions from, and evaluate decision tree models.
- Tune `max_depth`, `min_samples_split`, `min_samples_leaf` to get the best possible tree.
- Visualize a decision tree.

## Prerequisites
- Write and run Python code in a Jupyter notebook.
- Create basic Python functions.
- Have familiarity with `pandas`.
- Have familiarity with `scikit-learn`.
- Understand what supervised learning is, and how to run linear regression and a logistic regression and / or knn classification model.
