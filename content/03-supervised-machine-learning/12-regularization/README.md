## About
Understand what regularization is, the different types you can apply (LASSO, Ridget and ElasticNet), and their impact on the bias-variance tradeoff.  Also implement these types of regularized regression.


## Learning Objectives

*You will be able to:*

- Define and describe regularization for regression models.
- Understand the causes of overfitting in linear models.
- Describe how regularization effects regression coefficients.
- Compare Ridge, Lasso, and ElasticNet regularization techniques.
- Implement regularized models using `scikit-learn`.

- Interpret and use Python dictionaries.
